Core Features & Architecture

🤖 Multi-Engine Support

Compatible with ChatGPT, Claude, Gemini, DeepL, SiliconFlow, and local models (Ollama). Configure custom API endpoints seamlessly.

🎯 Visual Element Picker

Skip layout breakage. Mira focuses on main content areas out of the box. Select or exclude specific DOM elements visually without coding.

▶️ YouTube Integration

Dual-language subtitle rendering with player adjustments. Click any word to translate via AI context-awareness.

☁️ WebDAV & Drive Sync

Supports syncing your customized API configurations and saved vocabulary lists securely via Google Drive or WebDAV.

📚 Vocabulary Learning

Save words directly from translated text into a local list with context and phonetics. Review and cross-device sync ready.

📱 Mobile Support

Fully compatible with mobile browsers supporting extensions (e.g., Firefox and Edge on Android) for on-the-go translation.
